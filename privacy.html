Политика конфиденциальности Pomoshnik

Pomoshnik — личное приложение одного пользователя, его владельца. Другим людям оно не предоставляется.

Какие данные используются

С разрешения владельца приложение читает и меняет события его Google Календаря и читает и создаёт его Google Задачи (название, срок, заметку, отметку о выполнении).

Где хранятся данные

Данные хранятся только на компьютере владельца. Приложение не передаёт их третьим лицам, не продаёт и не использует для рекламы.

Как отозвать доступ

Доступ отзывается в любой момент на странице myaccount.google.com/permissions.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.
